FlashDB
github.com/Rhythm1710

Redis-compatible.
Written in Rust.
In memory.

FlashDB speaks the RESP protocol, so you can talk to it with any Redis client — redis-cli, language bindings, or redis-benchmark.

Get started 
$ cargo run --release
# listens on 127.0.0.1:6379

$ redis-cli -p 6379 ping
PONG

RDB snapshots

SAVE and BGSAVE write Redis's own binary format.

Replication

Master or replica, including a real redis-server.

Transactions

MULTI, EXEC, DISCARD, and WATCH.

Value types

  • string
  • list
  • hash
  • stream
  • zset

From the implemented command set

Commands

FlashDB implements a focused Redis subset — keys, lists, hashes, streams, sorted sets, pub/sub, transactions, and persistence.
